MY AI VIDEO STUDIO — BEGINNER STARTER

What this is:
- A static website prototype with Text-to-Video and Image-to-Video modes.
- Image preview, prompt input, aspect ratio and duration controls.
- It DOES NOT generate real AI videos yet. No AI model/backend is connected.

Run locally:
1. Extract this ZIP.
2. Open the my_ai_video_studio folder.
3. Double-click index.html. It opens in your browser.
4. Try both modes. The Generate button prepares a request summary only.

Publish a learning/demo version:
1. Sign in to GitHub and create a new public repository.
2. Upload index.html to the repository root.
3. Open repository Settings -> Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the Pages URL to appear.

Important:
- GitHub Pages only hosts the static frontend. It does not run AI video models.
- Do not use Google Colab as a permanent backend or web server; free Colab is for interactive compute and has variable limits.
- Real generation requires a supported GPU/model runtime or an independently hosted backend. Free availability is not guaranteed and cannot be unlimited.
- Do not add private API keys to index.html or any public repository.
